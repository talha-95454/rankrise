# RankRise — ASO Studio

Free ASO tool for Google Play keyword research, deployed as a Docker web
service (Render free tier) from this repository.

- **My Apps** — save each app's name, title, short & long description,
  seed keyword, country and feature graphic (with a 1024 x 500 size
  check). Saved apps are stored in your own browser.
- **Keyword Research** — enter a seed keyword and the server fetches live
  competitor apps from Google Play, copies their titles and short/long
  descriptions, and extracts their keywords. Download the competitors
  sheet, the all-keywords sheet, or the final sheet (CSV / Excel) in the
  AppKittie format: Country, Keyword, Popularity, Difficulty, Apps Count —
  sorted by Popularity, high to low.
- **Character Counter** — Play Store limits built in: title 30, short
  description 80, long description 4000 characters; over the limit turns
  red, plus a general characters/words/sentences counter.

Popularity and Difficulty are local estimates from real competitor
behaviour — not paid-tool data.
